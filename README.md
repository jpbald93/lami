# Lami's theorem in Lean 4

A Lean 4 + Mathlib formalisation of **Lami's theorem** on three concurrent forces in equilibrium,
in oriented and unoriented forms, with a converse.

> If three nonzero forces `F₁, F₂, F₃` satisfy `F₁ + F₂ + F₃ = 0`, then
> `‖F₁‖ / sin α = ‖F₂‖ / sin β = ‖F₃‖ / sin γ`, where `α, β, γ` are the angles between `F₂` and `F₃`,
> `F₃` and `F₁`, and `F₁` and `F₂`; and if the forces are not all parallel, these sines are nonzero.

The unoriented results hold in any real inner product space; the oriented ones in an oriented
two-dimensional one (`Orientation.oangle`), with a corollary for `ℂ`. The proofs go through area
forms and Gram determinants.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 17 named declarations.

## Main statements

| Lean name | File:line | Statement |
|---|---|---|
| `Lami.lami_nondegenerate` | `Lami/Basic.lean:180` | the classical theorem: equal ratios with nonzero denominators (forces nonzero, `F₁, F₂` not parallel) |
| `Lami.lami` | `Lami/Basic.lean:148` | equal ratios `‖Fᵢ‖ / sin(opposite angle)` (unoriented) |
| `Lami.lami_mul` | `Lami/Basic.lean:134` | division-free product form; equilibrium only |
| `Lami.lami_oriented`, `lami_oriented_mul` | `Lami/Basic.lean:100`, `:49` | oriented versions with `Real.Angle.sin (o.oangle …)` |
| `Lami.lami_complex` | `Lami/Basic.lean:111` | the oriented version in `ℂ` |
| `Lami.lami_oriented_converse` | `Lami/Basic.lean:262` | converse: nonzero forces, nonzero oriented sines and equal ratios ⇒ `F₁ + F₂ + F₃ = 0` |
| `Lami.lami_degenerate` | `Lami/Basic.lean:189` | if `F₁ ∥ F₂`, all three sines vanish (the ratio form then holds only via `x/0 = 0`) |
| `Lami.lami_cross` | `Lami/Basic.lean:211` | `‖F₁‖ sin β = ‖F₂‖ sin α`, needs only `F₃ ≠ 0` |

The converse fails with unoriented angles (replace `F₁` by `−F₁`); this is noted in the source.
`lami_via_law_sin` (`:220`) only re-exports Mathlib's vector law of sines and is not used.

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for 17 named
declarations, fully qualified (every declaration cited in `SPIKE_REPORT.md`, plus every name
queried by the axiom scratch file `AxCheck.lean`). The queries are generated by the gate itself, not read
from a file in the repository.

The gate fails if any of the following is true:
- a source file (`Lami/*.lean`, `Lami.lean`) contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `initialize`, `IO`, `set_option`, `macro`/`elab`/`syntax`/`notation`/`infix`/`prefix`/`postfix`, `import Lean` or `open Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (17 declarations, standard axioms only)`. Some of these are definitions, which may
use a subset of the three axioms.

`tests/tamper.sh` plants six kinds of fake proof in scratch copies (in `Lami/Basic.lean`) and checks
that the gate rejects each one (a rejection must exit nonzero and print the expected `FAIL`
message). The real repository is never modified.

| Test | What it plants |
|---|---|
| sorry | a `sorry` |
| ax2line | an axiom split across two lines |
| evalfake | an `#eval` that prints a fake axiom report |
| macro | a custom macro that rewrites `#print axioms` |
| falsehyp | the hypothesis `angle F₁ F₂ ≠ π` dropped from `lami_nondegenerate` (false for antiparallel `F₁, F₂`) |
| wrap | a genuine extra axiom with a long name, so the report wraps over several lines |

`tests/tamper.sh` needs a prior `lake build` (it reuses `.lake/build`); run the tests one at a time.

`python3 code/check_lami.py` checks the identities on 100 000 random equilibrium triples and the
collinear case. `AxCheck.lean` (outside the library) is the axiom query recorded during
development. `SPIKE_REPORT.md` is the development log.

## Prior art

Mathlib's `docs/1000.yaml` lists Lami's theorem with no declaration. GitHub code search for "Lami
theorem" and "lami" in Lean (51 and 68 hits) returned only false positives; repository search found
one Java and one HTML project; Mathlib issues and pull requests returned nothing. Mathlib has the
law of sines (`EuclideanGeometry.law_sin`) but no statement about equilibrium of forces. As far as
these searches go, this is the first formal proof of Lami's theorem; the searches are not
exhaustive.

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Toolchain: Lean `v4.33.1`, Mathlib `v4.33.1` (revision pinned in `lake-manifest.json`).
`gate.sh` never fetches: run `lake exe cache get` (or `lake build`) first so that the pinned
Mathlib checkout is present in `.lake/packages`.
